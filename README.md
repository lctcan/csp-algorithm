# csp-algorithm
csp算法题标准解法

BFS的核心思想："层层推进，由近及远"     
方向：“水面扩散” ，从起点开始，先访问所有直接邻居，然后访问邻居的邻居 ，一层一层向外扩展，直到覆盖所有可达节点  
适用：找到最短路径（总是访问当层所有可访问的节点，访问完才开始访问下一节点，第一次遇到终点时必然是最短路径） 
内存：存贮的是整层节点（存的比较多）
实现：用数据结构队列实现

都有这些基本东西
int net[MAX][MAX] // 二维数组的地图
int dx[4] = {-1,1,0,0} // 方向数组， 遍历时，需要有当前坐标和下一坐标
int dy[4] = {0,0,1,-1}
int visited[MAX] // 标记已访问
